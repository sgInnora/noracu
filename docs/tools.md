Returns {scale, logical_size, screen}; click coordinates are in points (pixels / scale). |
| `mac_ax_state` | app:string?, interactive:boolean?, compact:boolean?, skeleton:boolean?, root:integer?, snapshot_id:string?, surface:string?, window:string?, window_id:integer?, depth:number?, max_nodes:integer?, web_accessibility:boolean? | Read an app's accessibility tree through the macOS Accessibility API (default: the frontmost app's focused window). | `mac_click` | element_index:integer?, snapshot_id:string?, x:number?, y:number?, app:string?, force:boolean?, button:string?, count:number?, mechanism:string?, timeout_ms:integer? | Click a UI element by element_index (from mac_ax_state / mac_find; valid 30 s) or at raw {x,y}. A raw {x,y} click is sent only when the window on top at that point belongs to app (default: the frontmost app; the menu bar counts as the frontmost app's) — otherwise occluded names what covers it and nothing is sent; force:true skips that check. Results state delivery (delivered_verified / delivered_unverified / not_delivered / unknown) and whether a retry is safe, plus newly opened sheets, dialogs or menus. |
| `mac_drag` | **from_index**:integer, **to_index**:integer, snapshot_id:string? | Drag from one UI element to another (sliders, selections, list items) with the physical pointer; from_index/to_index come from mac_ax_state or mac_find (valid 30 s). | `mac_scroll` | direction:string?, pages:number?, element_index:integer?, snapshot_id:string? | Scroll up/down/left/right by a number of pages (default 1). Without element_index: the frontmost window (the pointer moves there). With element_index: a scroll area is scrolled at its own center (hit-tested; reports when the position did not change), any other element is scrolled into view (AXScrollToVisible). |
| `mac_key` | **key**:string, app:string?, force:boolean? | Press a key or modifier chord, e.g. 'return', 'esc', 'cmd-c', 'cmd-shift-v', 'arrow-up'. Named keys (return, esc, tab, space, delete, arrows, home/end, page keys, F1-F16), with or without modifiers, go out as HID key events with each modifier pressed and released around the key; chords on a character key (cmd-c) go through cliclick. Pass app to refuse input unless that app is frontmost (focus guard). Chords that quit, log out, lock, force-quit, delete immediately or empty the Trash (cmd-q, alt-cmd-q, cmd-shift-q, cmd-alt-esc, ctrl-cmd-q, cmd-alt-delete, cmd-shift-delete…) are refused unless force:true. |
| `mac_type` | **text**:string, element_index:integer?, snapshot_id:string?, app:string?, replace:boolean?, mechanism:string?, timeout_ms:integer? | Type text into element_index, or into the focused element (of app, if given). mechanism auto (default): inserted through accessibility at the caret (AXSelectedText) — IME-safe, clipboard untouched, works in a background app, verified by reading the value back; replace:true sets the whole value instead. If the focused element takes no text through accessibility, auto falls back to physical keystrokes (not IME-safe; app is then a focus guard: refused unless that app is frontmost). mechanism physical forces keystrokes (clicking element_index first). |
| `mac_paste` | **text**:string, app:string?, force:boolean? | Paste text with Cmd+V through the clipboard, then put the user's clipboard back: every item and type is copied aside and restored within one call, only after the paste shows in the focused element (else after a 1 s hold) and only if nothing else wrote to the clipboard meanwhile; a password manager's concealed item is never copied — the clipboard is cleared after the paste instead. The pasted text is marked transient for clipboard managers. Pass app to refuse input unless that app is frontmost (focus guard). Refused when the clipboard holds Universal Clipboard content or more than 64 MB (force:true pastes anyway and leaves the pasted text on the clipboard). mac_type does not touch the clipboard. |
| `mac_menu_command` | **app**:string, **command**:string, force:boolean? | Run an app's menu bar command through accessibility (AXPress on the item: no pointer, the app need not be frontmost). command is the item title as the app shows it (unique in the menu bar) or a path such as "File > Export > PDF…"; an item that reads disabled is still pressed (closed menus report stale state) and the result says whether anything changed; reports delivery and any sheet or dialog it opened. Menu items under the Apple menu and items whose keyboard shortcut is one of the refused chords need force:true; Quit of the MCP host or of a macOS session process is always refused. |
| `mac_wait` | **condition**:string, app:string?, title:string?, text:string?, exact:boolean?, window:string?, element_index:integer?, snapshot_id:string?, predicate:string?, value:string?, timeout_ms:integer? | Wait (instead of sleeping) until a condition holds, polling accessibility: window / window_gone (title substring, app), text / text_gone (in app's window), element (element_index + predicate exists\|gone\|enabled\|focused\|value_equals\|value_contains, value), menu / menu_closed, sheet / sheet_gone (sheet, alert or dialog), app_running / app_gone, notification (a new one, optional app / text; refused under NORACU_READ_ONLY=1). For window_gone, text_gone, menu_closed and sheet_gone the app must be running when the wait starts (a misspelled or non-running app fails immediately with app_not_found). timeout_ms default 10000, max 30000; on timeout returns what it last saw. |
| `mac_app` | **action**:string, **app**:string, activate:boolean?, wait_window:boolean?, force:boolean?, cdp_port:integer?, timeout_ms:integer? | Launch, activate, hide, unhide or quit an app (display name, bundle id, or .app path). launch: attaches to a running instance (activate:true brings it forward), else starts it in the background unless activate:true and waits for a window (wait_window, default true). quit: graceful, verified by the process ending (a save dialog keeps it running — reported); force:true force-quits and loses unsaved work. Finder, Dock, loginwindow and other session processes, and the MCP host itself, are never quit. launch with cdp_port (0 = pick a free port; needs NORACU_ALLOW_CDP=1) starts a Chromium/Electron app fresh with a loopback DevTools port for browser_launch cdp_port — refused if the app is already running. |
| `mac_window` | **action**:string, window_id:integer?, app:string?, window:string?, x:number?, y:number?, width:number?, height:number? | Focus, raise, minimize, restore, move (x,y), resize (width,height), maximize (fill the display's visible area), fullscreen or exit_fullscreen a window, chosen by window_id (from mac_windows) or app + window (index or title); verified by reading the window again. |
| `mac_clipboard_read` | format:string?, max_chars:integer? | Read the clipboard: format auto (file paths, else image, else text), text, files or image (returned as an image). Text is capped at max_chars (default 20000). An item a password manager marked concealed is never returned. The clipboard can hold secrets: read it only when the task needs it. |
| `mac_notifications` | action:string?, app:string?, text:string?, id:string?, index:integer?, expected_app:string?, expected_title:string?, name:string?, open_center:boolean?, limit:integer? | List, dismiss or act on notifications visible to accessibility (banners and alerts on screen, and Notification Center while it is open; open_center:true checks whether Notification Center is already open and clicks the menu-bar clock only when closed). list returns {count, notifications:[{index, id, kind, app, title, subtitle, body, actions}], center_opened, center_was_open}, optional app / text filter (center_opened means this call opened and closed it; center_was_open means it was already open). dismiss or act (name: an action such as Show, Reply, or press) take a non-empty id from list (or a 1-based index plus non-empty expected_app / expected_title, re-checked so a reordered stack is not acted on); an absent id returns notification_not_found. | `mac_set_value` | **element_index**:integer, **value**:string, snapshot_id:string?, timeout_ms:integer? | Set an element's value by element_index, by role: text fields (whole value; AXSecureTextField never echoes the value), checkboxes / switches / radio buttons (true\|false, idempotent: nothing sent when already so; a mixed checkbox is pressed up to twice until it reaches the requested state), disclosure triangles and expandable rows (true\|false), rows / cells / tabs (true selects), pop-up buttons, menu buttons and combo boxes (an option's title: opens the menu, picks the one matching option, closes it again if none or several match), sliders / steppers (a number within min-max). | `mac_find` | app:string?, role:string?, title:string?, value:string?, text:string?, id:string?, exact:boolean?, limit:integer?, surface:string?, window:string?, window_id:integer?, web_accessibility:boolean? | Search an app's accessibility tree for elements by role (e.g. button, textfield, checkbox, row), title, value, text (title or value) or id (AXIdentifier); substring match, case-insensitive, unless exact:true. | `mac_get` | **element_index**:integer, snapshot_id:string?, max_chars:integer? | Read one element live by element_index: role, title, description, value (up to max_chars, default 4000), frame, states (checked, selected, focused, disabled, expanded…), actions, settable attributes, help. ## Browser layer (browser-use)

*Playwright*

| Tool | Arguments | Description |
|---|---|---|
| `browser_launch` | headless:boolean?, cdp_port:integer? | Launch the browser with a persistent profile (headed by default; pass headless:true for headless). With cdp_port: attach to a Chromium/Electron app started by this server's mac_app launch cdp_port (needs NORACU_ALLOW_CDP=1; attaching to any other loopback port needs NORACU_ALLOW_CDP=any; refused under NORACU_READ_ONLY=1 and while another session is open; standalone browser_launch is also refused while a CDP session is open). browser_close then only disconnects. |
| `browser_navigate` | **url**:string | Navigate the active page to an http(s) URL (file:// is disabled unless NORACU_ALLOW_FILE_URL=1). Reports the final URL, HTTP status (or "no response" for same-document navigations), title, and delivery/retry. |
| `browser_snapshot` | browser_id:string? | Return the active page's ARIA accessibility snapshot plus up to 100 indexed interactive elements (reporting truncation and omitted count beyond 100); indexes feed browser_click. The active page stays the tab noracu is driving: a tab the page opens itself (window.open, target=_blank) is never switched to; another tab becomes active only after the active one closes. |
| `browser_screenshot` | fullPage:boolean?, format:string?, quality:number?, clip:object? | Screenshot the active page with optional fullPage, format png\|jpeg, quality (1-100, jpeg) and clip {x,y,width,height} (uses scale:"css" when attached over CDP); returns the image plus DPR/viewport metadata. |
| `browser_click` | element_index:integer?, selector:string?, xy:array?, button:string? | Click an element on the active page, preferring element_index from the latest browser_snapshot of that page (valid 30 s; re-checks page, URL, tag, name, href and position, returning element_no_longer_valid when stale). Uses real Playwright pointer input with actionability checks (returns occluded or not_actionable when covered or disabled — never falls back to synthetic JS .click()). selector is a fallback; xy pixel coordinates are not recommended. Reports delivery and retry. |
| `browser_fill` | **selector**:string, value:string? | Fill an input field matched by selector; fill replaces the whole value (browser_type appends keystrokes). Reports delivery and retry. |
| `browser_press_key` | **key**:string | Press a key or chord, e.g. 'Enter' or 'Control+A'. Reports delivery and retry. |
| `browser_type` | **text**:string | Type up to 2000 characters via the keyboard into the focused element; type appends keystrokes (browser_fill replaces the whole value and suits longer text). Reports delivery and retry. |
| `browser_scroll` | direction:string?, pages:number? | Scroll the active page up, down, left, or right by a number of pages (default: down, 1 page) via mouse wheel at the viewport center; reports the scrollX/scrollY change (or "did not move") plus delivery and retry. |
| `browser_read` | selector:string? | Read the active page's visible text, optionally scoped to a selector. |
| `browser_evaluate` | **js**:string | Evaluate JavaScript in the active page and return the result plus delivery and retry (disabled when NORACU_DISABLE_EVAL=1). |
| `browser_close` | — | Close the browser (or disconnect from an attached CDP session). |
